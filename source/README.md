# Source artboards

Original mockup source, one file per artboard, plus `canvas.json` (positions, titles and notes for the canvas). These files use a design-canvas component format (`<x-dc>`, `{{holes}}`, `<sc-for>`) and need that editor's runtime to render; open the plain HTML files in the repo root to view the screens.

| `JobPage.dc.html` | `../job.html` |
